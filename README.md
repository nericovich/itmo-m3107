## Как добавлять материалы

- Сохраняйте конспекты лекций в `<Предмет>/Лекции/` с именем `ГГ.ММ.ДД Тема.md`.
- Сохраняйте Markdown-конспекты практик в `<Предмет>/Практики/` с именем `п_ГГ.ММ.ДД Тема.md`.
- При добавлении лекции или практики по ЛинАл или МатАн добавляйте ссылку к соответствующей теме в [указателе](Порядок%20тем%20ЛинАл%20и%20МатАн.md).
