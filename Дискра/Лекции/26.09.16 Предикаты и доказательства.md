## Часть 1. Логика предикатов и кванторы

### 1.1. Основные понятия
* **Предикат $P(x)$** — это высказывательная форма (шаблон), истинность которой зависит от значения входящей в неё переменной (или нескольких переменных). Сам по себе предикат не является высказыванием, пока в него не подставлено конкретное значение.
* **Предметная область (*Domain of discourse*)** — множество допустимых значений переменной $x$.
* **Свободные и связанные переменные:**
  * **Связанная переменная** — находится под действием квантора (например, $x$ в $\exists x. (P(x) \land Q(y))$).
  * **Свободная переменная** — не связана квантором ($y$ в примере выше). Формула со свободными переменными остаётся предикатом.

---

### 1.2. Кванторы
1. **Квантор всеобщности ($\forall$ — *for all*):**  
   $\forall x. P(x)$ — «для всех $x$ истинно $P(x)$».
   > *Примечание о пустом множестве:* Высказывание $\forall x \in \varnothing. P(x)$ **всегда истинно** (в пустой аудитории некому нарушить утверждение).

2. **Квантор существования ($\exists$ — *exists*):**  
   $\exists x. P(x)$ — «существует $x$, для которого истинно $P(x)$» (хотя бы один).

3. **Квантор единственности ($\exists!$):**  
   «Существует единственный $x$, такой что $P(x)$»:
   $$\exists! x. P(x) \equiv \exists x. \Big(P(x) \land \forall y. (P(y) \to y = x)\Big)$$

---

### 1.3. Отрицание кванторов (Законы де Моргана для кванторов)
Отрицание «проносится» через квантор, инвертируя сам квантор и навешивая отрицание на предикат:
* $\neg(\forall x. P(x)) \equiv \exists x. \neg P(x)$ *(«Не все $x$ обладают свойством $P$» $\equiv$ «Существует $x$, не обладающий $P$»)*.
* $\neg(\exists x. P(x)) \equiv \forall x. \neg P(x)$ *(«Не существует $x$ со свойством $P$» $\equiv$ «Все $x$ не обладают $P$»)*.

> **Важно:** «Не все» $\neq$ «Все не»:
> * «Не все сдали» $\to \exists x. \neg S(x)$ (хотя бы один не сдал).
> * «Все не сдали» $\to \forall x. \neg S(x)$ (не сдал никто).

---

### 1.4. Порядок кванторов
Порядок разнотипных кванторов **критически важен**:
* $\forall x \exists y. P(x, y)$ — для каждого $x$ подбирается *свой* $y$.
* $\exists y \forall x. P(x, y)$ — существует *один общий* $y$, подходящий сразу для всех $x$.

**Пример:**  
* $\forall x \exists y. (y > x)$ — истинно на $\mathbb{N}$ (для любого числа есть большее: $y = x + 1$).  
* $\exists y \forall x. (y > x)$ — ложно на $\mathbb{N}$ (нет универсального числа, которое больше всех натуральных).

---

### 1.5. Ограниченные кванторы (*Bounded Quantifiers*)

Когда квантор применяется к элементам конкретного подмножества $A$:

* **Всеобщность через импликацию:**  
  $$\forall x \in A.\, P(x) \iff \forall x.\, (x \in A \to P(x))$$  
  *(Если объект не принадлежит $A$, посылка $x \in A$ ложна, поэтому импликация автоматически истинна — вне множества $A$ от объекта ничего не требуется).*

* **Существование через конъюнкцию:**  
  $$\exists x \in A.\, P(x) \iff \exists x.\, (x \in A \land P(x))$$  
  *(Объект обязан одновременно и принадлежать множеству $A$, и обладать свойством $P$).*

* **Отрицание ограниченного квантора сохраняет область:**  
  $$\neg(\forall x \in A.\, P(x)) \equiv \exists x \in A.\, \neg P(x)$$  
  $$\neg(\exists x \in A.\, P(x)) \equiv \forall x \in A.\, \neg P(x)$$

---

### 1.6. Тонкости формализации естественного языка
* **Слово «только» (*Only*):** меняет направление импликации на противоположное.
  * *«Все отличники ($O$) получают стипендию ($S$)»*: $\forall x. (O(x) \to S(x))$
  * *«Только отличники получают стипендию»*: $\forall x. (S(x) \to O(x))$ *(если получает стипендию $\implies$ точно отличник)*.
* **Пример со свойствами массивов:**
  * «Массив $a$ длины $n$ отсортирован по возрастанию»:
    $$\forall i \in \{1, \dots, n-1\}. (a_i \le a_{i+1}) \quad \text{или} \quad \forall i. (1 \le i \le n-1 \to a_i \le a_{i+1})$$

---

### 1.7. Аналогия с программированием
Кванторы соответствуют проходу по коллекциям:
* $\forall$ $\longleftrightarrow$ метод `.all()` (проверяет все элементы, завершается при первом `false`).
* $\exists$ $\longleftrightarrow$ метод `.any()` (завершается при первом `true`).

```rust
// Rust
a.iter().all(|&v| v > 0);       // ∀i. a[i] > 0
a.iter().any(|&v| v <= 0);      // ∃i. ¬(a[i] > 0)
```

## Часть 2. Методы математических доказательств

**Доказательство** — проверяемая цепочка логических шагов, выводящая заключение из аксиом, определений и ранее доказанных теорем.

```
                  ┌─ Прямое доказательство (Direct proof)
                  ├─ Через контрапозицию (Contraposition: ¬Q → ¬P)
Методы ───────────┼─ От противного (Proof by contradiction)
доказательств     ├─ Разбор случаев (Proof by cases)
                  ├─ Контрпример (Counterexample — для опровержения ∀)
                  └─ Математическая индукция (Mathematical induction)
```

### 2.1. Классификация методов доказательства

| Метод | Суть метода | Пример / Схема |
| :--- | :--- | :--- |
| **Прямое доказательство** | Предполагаем посылку $P$, строим прямую логическую цепочку к $Q$. | $n$ чётно $\implies n = 2k \implies n^2 = 4k^2 = 2(2k^2) \implies n^2$ чётно. |
| **Через контрапозицию** | Доказываем эквивалентное утверждение: $\neg Q \to \neg P$. | Чтобы доказать «$n^2$ нечётно $\to n$ нечётно», доказываем: «$n$ чётно $\to n^2$ чётно». |
| **От противного** | Предполагаем истинность $\neg P$ и приходим к логическому противоречию ($R \land \neg R$). | Доказательство иррациональности $\sqrt{2}$. |
| **Разбор случаев** | Множество всех возможностей разбивается на конечное число непересекающихся условий. | Доказательство $|x| \cdot |y| = |xy|$ для случаев: нули, одинаковые знаки, разные знаки. |
| **Доказательство эквивалентности** | Чтобы доказать $P \leftrightarrow Q$, доказывают две импликации: $P \to Q$ и $Q \to P$. | $n$ чётно $\iff n^2$ чётно (прямое + контрапозиция). |
| **Опровержение контрпримером** | Чтобы опровергнуть $\forall x. P(x)$, достаточно найти ровно один $x_0$, где $\neg P(x_0)$. | «Все простые числа нечётны» опровергается числом $2$. |

---

### 2.2. Логические ошибки (Ловушки рассуждений)
1. **Аффирмация консеквента (*Affirming the consequent*):**
   * Ошибка: из $P \to Q$ и $Q$ выводить $P$.
   * *Пример:* «Если идёт дождь ($P$), земля мокрая ($Q$)». Земля мокрая $\not\implies$ был дождь (её могли полить).
2. **Отрицание антецедента (*Denying the antecedent*):**
   * Ошибка: из $P \to Q$ и $\neg P$ выводить $\neg Q$.
   * *Пример:* Дождя нет $\not\implies$ земля обязательно сухая.

## Часть 3. Математическая индукция

Принцип домино: если падает первая кость и каждая упавшая кость роняет следующую — упадут все кости.

### 3.1. Классическая индукция
Для доказательства $\forall n \ge n_0. P(n)$:
1. **База индукции:** Проверить истинность $P(n_0)$.
2. **Индукционный переход (шаг):** Доказать, что $\forall k \ge n_0: P(k) \implies P(k+1)$.

---

### 3.2. Сильная индукция
В индукционном переходе мы предполагаем истинность утверждения **для всех** значений от базы до $k$:
* **База:** $P(n_0)$.
* **Шаг:** $\Big( \forall i \in [n_0, k). P(i) \Big) \implies P(k)$.

> **Пример применения:** Основная теорема арифметики (любое $n > 1$ раскладывается в произведение простых чисел). При делении $k = a \cdot b$ о сомножителях $a$ и $b$ известно лишь то, что они строго меньше $k$, поэтому предположения только для $k-1$ недостаточно.

---

### 3.3. Принцип наименьшего числа (*Well-Ordering Principle*)
> Всякое непустое подмножество натуральных чисел $\mathbb{N}$ содержит наименьший элемент.

*Принцип наименьшего числа логически эквивалентен принципу математической индукции.* Часто используется в доказательствах от противного: «Предположим, утверждение неверно. Тогда выберем **минимальный контрпример** $m$…»

---

### 3.4. Индукция в Computer Science и частые ошибки
* **Инвариант цикла** — предикат, истинный перед началом цикла и сохраняющийся после каждой итерации. Корректность цикла доказывается индукцией по номеру итерации.
* **Рекурсия** — индуктивное построение алгоритма (базовый случай = база индукции, рекурсивный вызов = индукционный переход).
* **Ловушка «краевого случая» (Парадокс лошадей):**
  * В софизме «все лошади одного цвета» шаг от $k$ к $k+1$ полагается на непустое пересечение двух подгрупп лошадей.
  * При переходе от $k=1$ к $k=2$ размер пересечения равен $2 - 2 = 0$. Пересечение пусто, цвет перенести нельзя — доказательство ломается именно на переходе $1 \to 2$.

## Ответы на вопросы для самопроверки (Слайд 43)

#### 1. Запишите кванторами: «в любом классе есть отличник».
* **Обозначения:** $C$ — множество классов, $S(c)$ — множество учеников в классе $c$, $E(x)$ — предикат «$x$ — отличник».
* **Формула:**
  $$\forall c \in C. \exists x \in S(c). E(x)$$

---

#### 2. Запишите и прочитайте по-русски отрицание: $\neg(\exists x \in A. P(x))$.
* **Преобразование:**
  $$\neg(\exists x \in A. P(x)) \equiv \forall x \in A. \neg P(x)$$
* **Чтение:** «Для любого элемента $x$ из множества $A$ утверждение $P(x)$ ложно» (или: «Ни один элемент из множества $A$ не обладает свойством $P$»).

---

#### 3. Докажите: если $n^2$ делится на 3, то $n$ делится на 3.
* **Метод:** Контрапозиция ($\neg Q \to \neg P$).  
* Докажем: «Если $n$ не делится на 3, то $n^2$ не делится на 3».
  * **Случай 1:** $n = 3k + 1$.  
    $$n^2 = (3k + 1)^2 = 9k^2 + 6k + 1 = 3(3k^2 + 2k) + 1 \implies \text{остаток } 1 \ne 0.$$
  * **Случай 2:** $n = 3k + 2$.  
    $$n^2 = (3k + 2)^2 = 9k^2 + 12k + 4 = 3(3k^2 + 4k + 1) + 1 \implies \text{остаток } 1 \ne 0.$$
* В обоих случаях $n^2$ не делится на 3. Контрапозиция доказана, следовательно, исходное утверждение верно. $\blacksquare$

---

#### 4. Найдите контрпример к утверждению: «все нечётные числа простые».
* **Контрпример:** Число $9$ (или $15, 21, 25, \dots$). Число $9$ является нечётным ($9 = 2 \cdot 4 + 1$), но составным ($9 = 3 \cdot 3$).

---

#### 5. Докажите индукцией: $1 + 3 + 5 + \dots + (2n - 1) = n^2$.
* **База ($n = 1$):**  
  $2(1) - 1 = 1$, правая часть $1^2 = 1$. $1 = 1$ — верно.
* **Индукционный переход:**  
  Пусть равенство верно для $n = k$:  
  $$1 + 3 + \dots + (2k - 1) = k^2$$
  Докажем для $n = k + 1$:
  $$\underbrace{1 + 3 + \dots + (2k - 1)}_{= k^2} + (2(k + 1) - 1) = k^2 + 2k + 1 = (k + 1)^2$$
  Равенство выполняется для $k + 1$. Утверждение доказано для всех $n \ge 1$. $\blacksquare$

---

#### 6. Чем $\forall x \exists y. P(x, y)$ отличается от $\exists y \forall x. P(x, y)$?
* В $\forall x \exists y. P(x, y)$ выбор $y$ может зависеть от $x$ (свой $y$ для каждого $x$).
* В $\exists y \forall x. P(x, y)$ существует фиксированный $y$, единый и универсальный сразу для всех $x$.
* $\exists y \forall x. P(x, y) \implies \forall x \exists y. P(x, y)$, но обратное в общем случае неверно.

---

#### 7. Запишите формулой «только отличники получают стипендию» и её отрицание.
* **Предикаты:** $E(x)$ — $x$ отличник, $S(x)$ — $x$ получает стипендию.
* **Прямое утверждение:**  
  $$\forall x. (S(x) \to E(x))$$
* **Отрицание:**
  $$\neg\Big(\forall x. (S(x) \to E(x))\Big) \equiv \exists x. \neg(S(x) \to E(x)) \equiv \exists x. (S(x) \land \neg E(x))$$
  *(Существует студент, который получает стипендию, не будучи отличником).*
