# Лекция: Выпуклые функции и производная показательной функции

**Ключевые вопросы лекции:**
* Определение выпуклой функции и её геометрическая интерпретация.
* Критерий выпуклости для непрерывных функций (выпуклость по Йенсену).
* Лемма о трёх хордах (монотонность угловых коэффициентов секущих).
* Непрерывность выпуклой функции на внутренних отрезках области определения.
* Производная показательной функции $a^x$ и существование предела $\lim\limits_{h \to 0} \frac{a^h - 1}{h}$.

## 1. Выпуклые функции

> **Определение 1 (Выпуклая функция)**: Пусть $I \subset \mathbb{R}$ — связное множество (интервал, полуинтервал или отрезок). Функция $f: I \to \mathbb{R}$ называется **выпуклой**, если $\forall x, y \in I$ и $\forall t \in [0, 1]$ выполняется неравенство:
> $$f((1-t)x + ty) \le (1-t)f(x) + tf(y)$$

> 💡 **Интуиция / Геометрический смысл:**
> Выпуклость функции означает выпуклость её **надграфика**: для любых двух точек $x, y \in I$ дуга графика функции между точками $(x, f(x))$ и $(y, f(y))$ лежит не выше хорды, соединяющей эти точки. В частности, при $t = \frac{1}{2}$ значение в середине отрезка $f\left(\frac{x+y}{2}\right)$ не превосходит полусуммы значений на концах $\frac{f(x)+f(y)}{2}$ (классический пример — функция $f(x) = e^x$).

> **Утверждение 1 (Критерий выпуклости непрерывной функции)**: Пусть функция $f: I \to \mathbb{R}$ непрерывна на $I$. Если для любых $x, y \in I$ выполняется неравенство
> $$f\left(\frac{x+y}{2}\right) \le \frac{f(x) + f(y)}{2},$$
> то функция $f$ является выпуклой на $I$.

**Доказательство:**
**Шаг 1.** Покажем, что неравенство выпуклости верно для всех двоично-рациональных чисел вида $t = \frac{k}{2^n}$, где $0 \le k \le 2^n$.
Докажем это индукцией по $n$:
* *База индукции:* Для $n = 0, 1$ утверждение очевидно ($t \in \{0, 1, \frac{1}{2}\}$ — верно тривиально или непосредственно из условия утверждения).
* *Индукционный переход:* Пусть неравенство доказано для всех дробей со знаменателем $2^n$. Обозначим для краткости $z(t) = (1-t)x + ty$.
  Рассмотрим $t = \frac{k}{2^{n+1}}$.
  1. Если $k = 2j$ (чётное), то $t = \frac{j}{2^n}$, и неравенство верно по предположению индукции.
  2. Пусть $k = 2j + 1$ (нечётное). Положим $t_- = \frac{j}{2^n}$ и $t_+ = \frac{j+1}{2^n}$. Тогда $t = \frac{t_- + t_+}{2}$ и, в силу линейности $z(t)$, имеем $z(t) = \frac{z(t_+) + z(t_-)}{2}$.
  Применяя условие утверждения для середины отрезка и предположение индукции для точек $t_-$ и $t_+$, получаем:
  $$\begin{aligned}
  f(z(t)) &= f\left(\frac{z(t_-) + z(t_+)}{2}\right) \le \frac{f(z(t_-)) + f(z(t_+))}{2} \le \\
  &\le \frac{(1 - t_-)f(x) + t_- f(y) + (1 - t_+)f(x) + t_+ f(y)}{2} = \\
  &= \underbrace{\frac{2 - t_- - t_+}{2}}_{1 - t} f(x) + \underbrace{\frac{t_+ + t_-}{2}}_{t} f(y) = (1-t)f(x) + tf(y).
  \end{aligned}$$
  Индукционный переход доказан.

**Шаг 2.** Пусть теперь $t \in [0, 1]$ — произвольное вещественное число. Положим
$$t_n = \frac{\lfloor 2^n \cdot t \rfloor}{2^n}.$$
По определению целой части числа выполняются неравенства:
$$2^n t - 1 < \lfloor 2^n t \rfloor \le 2^n t < \lfloor 2^n t \rfloor + 1,$$
откуда после деления на $2^n$ получаем:
$$t - \frac{1}{2^n} < \frac{\lfloor 2^n t \rfloor}{2^n} \le t \implies 0 \le t - t_n < \frac{1}{2^n}.$$
При $n \to \infty$ величина $\frac{1}{2^n} \to 0$, следовательно, последовательность двоично-рациональных точек $t_n \to t$.

Так как для каждого $t_n$ неравенство выпуклости уже доказано на Шаге 1, имеем:
$$f((1 - t_n)x + t_n y) \le (1 - t_n)f(x) + t_n f(y).$$
Переходя к пределу при $n \to \infty$ и пользуясь непрерывностью функции $f$, получаем требуемое неравенство:
$$f((1-t)x + ty) \le (1-t)f(x) + tf(y). \quad \blacksquare$$

**Пример:**
Рассмотрим показательную функцию $f(x) = a^x$ при $a > 0$. Функция непрерывна, и по неравенству о среднем арифметическом и среднем геометрическом для любых $x, y \in \mathbb{R}$ выполняется:
$$f\left(\frac{x+y}{2}\right) = a^{\frac{x+y}{2}} = \sqrt{a^x \cdot a^y} \le \frac{a^x + a^y}{2} = \frac{f(x) + f(y)}{2}.$$
Следовательно, по Утверждению 1 функция $f(x) = a^x$ выпукла на $\mathbb{R}$.

## 2. Свойства секущих и непрерывность выпуклых функций

> **Лемма 1 (О трёх хордах / о возрастании наклона секущих)**: Пусть $f: I \to \mathbb{R}$ — выпуклая функция. Тогда для любых $x < y < z$ из $I$ выполняются неравенства:
> $$\frac{f(y) - f(x)}{y - x} \le \frac{f(z) - f(x)}{z - x} \le \frac{f(z) - f(y)}{z - y}.$$

**Доказательство:**
Представим среднюю точку $y$ как выпуклую комбинацию крайних точек $x$ и $z$:
$$y = (1-t)x + tz, \quad \text{где } t = \frac{y-x}{z-x} \in (0, 1), \quad 1-t = \frac{z-y}{z-x}.$$
По определению выпуклости функции $f$:
$$f(y) \le \frac{z-y}{z-x} f(x) + \frac{y-x}{z-x} f(z).$$
Умножим обе части неравенства на положительную величину $(z-x) > 0$:
$$(z-x)f(y) \le (z-y)f(x) + (y-x)f(z). \quad (*)$$

1. **Докажем первое неравенство.** Вычтем из обеих частей неравенства $(*)$ величину $(z-x)f(x)$ и преобразуем правую часть:
   $$\begin{aligned}
   (z-x)f(y) &\le z f(x) - y f(x) + y f(z) - x f(z) \\
   (z-x)f(y) - (z-x)f(x) &\le (y-x)f(z) - (y-x)f(x) \\
   (z-x)(f(y) - f(x)) &\le (y-x)(f(z) - f(x)).
   \end{aligned}$$
   Разделив обе части на положительное произведение $(y-x)(z-x) > 0$, получаем левое неравенство:
   $$\frac{f(y) - f(x)}{y - x} \le \frac{f(z) - f(x)}{z - x}.$$

2. **Докажем второе неравенство.** Аналогично из соотношения $(*)$ выразим разность для точки $z$:
   $$\begin{aligned}
   (z-x)f(z) - (z-x)f(y) &\ge (z-x)f(z) - (z-y)f(x) - (y-x)f(z) = \\
   &= (z-y)f(z) - (z-y)f(x) = (z-y)(f(z) - f(x)).
   \end{aligned}$$
   Разделив на $(z-x)(z-y) > 0$, получаем правое неравенство:
   $$\frac{f(z) - f(x)}{z - x} \le \frac{f(z) - f(y)}{z - y}. \quad \blacksquare$$

> **Следствие 1 (Непрерывность выпуклой функции)**: Если функция $f: I \to \mathbb{R}$ выпукла на открытом интервале $I$ (или в окрестности рассматриваемых точек), то $f$ непрерывна на $I$.

**Доказательство:**
Возьмём произвольный отрезок $[p, q] \subset I$, лежащий строго внутри $I$, так что существуют точки $u, v \in I$, для которых выполняется $u < p < q < v$.
Пусть $x, y \in [p, q]$ и, без ограничения общности, $x < y$. Тогда точки расположены в следующем порядке:
$$u < p \le x < y \le q < v.$$
По Лемме 1 (о монотонности наклонов хорд) при сдвиге концов отрезка вправо угловой коэффициент секущей не убывает, поэтому:
$$L := \frac{f(p) - f(u)}{p - u} \le \frac{f(y) - f(x)}{y - x} \le \frac{f(v) - f(q)}{v - q} =: R.$$
Положим константу $C = \max\{|L|, |R|\}$. Тогда для любых $x, y \in [p, q]$ выполняется условие Липшица:
$$|f(y) - f(x)| \le C |y - x|.$$
Проверим непрерывность по определению: для любого $\varepsilon > 0$ выберем $\delta = \frac{\varepsilon}{C} > 0$. Тогда для всех $x, y \in [p, q]$ из условия $|y - x| < \delta$ следует, что $|f(y) - f(x)| < C \cdot \frac{\varepsilon}{C} = \varepsilon$. Следовательно, $f$ непрерывна на $[p, q]$, а в силу произвольности отрезка — и во всех внутренних точках $I$. $\blacksquare$

## 3. Производные элементарных функций: $a^x, \log_a(x), x^\alpha$

Рассмотрим задачу вычисления производной показательной функции $f(x) = a^x$ ($a > 0$):
$$(a^x)' = \lim_{h \to 0} \frac{a^{x+h} - a^x}{h} = a^x \lim_{h \to 0} \frac{a^h - 1}{h}.$$
Таким образом, для того чтобы найти производную в любой точке $x$, достаточно доказать существование предела в точке $0$:
$$\lim_{h \to 0} \frac{a^h - 1}{h} = \ell(a).$$
Ниже мы будем изучать функцию $\ell(a)$ (которая, как выяснится далее в курсе, совпадает с натуральным логарифмом $\ln(a)$).

> **Лемма 2**: Для любого $a > 1$ (и аналогично для $a > 0$) существует конечный предел
> $$\lim_{h \to 0} \frac{a^h - 1}{h} = \ell(a),$$
> причём выполняется двусторонняя оценка:
> $$1 - \frac{1}{a} \le \ell(a) \le a - 1.$$

**Доказательство:**
Рассмотрим вспомогательную функцию углового коэффициента секущей для функции $t \mapsto a^t$, проведённой из точки $(0, 1)$:
$$f(t) = \frac{a^t - 1}{t} = \frac{a^t - a^0}{t - 0}.$$

**Шаг 1 (Монотонность $f(t)$).**
Так как функция $g(t) = a^t$ выпукла на $\mathbb{R}$, по Лемме 1 для любых $0 < s < t$ выполняется неравенство:
$$\frac{a^s - 1}{s} \le \frac{a^t - 1}{t},$$
то есть функция $f(t)$ монотонно не убывает при $t > 0$ ($f(t) \uparrow$).

**Шаг 2 (Двусторонняя оценка на интервале $(0, 1)$).**
Рассмотрим $t \in (0, 1)$ и оценим $f(t)$ сверху и снизу:
1. *Оценка сверху:* Представим $t = (1-t)\cdot 0 + t \cdot 1$. По определению выпуклости функции $a^t$ на отрезке $[0, 1]$ имеем:
   $$a^t \le (1-t)a^0 + t a^1 = (1-t)\cdot 1 + t \cdot a = 1 + t(a - 1).$$
   Отсюда сразу следует:
   $$f(t) = \frac{a^t - 1}{t} \le a - 1.$$
2. *Оценка снизу:* Представим точку $0$ как выпуклую комбинацию точек $-1$ и $t$:
   $$0 = \frac{t}{t+1}(-1) + \frac{1}{t+1} t.$$
   В силу выпуклости функции $a^x$ на отрезке $[-1, t]$ получаем:
   $$1 = a^0 \le \frac{t}{t+1} a^{-1} + \frac{1}{t+1} a^t.$$
   Умножим обе части неравенства на $t + 1 > 0$:
   $$t + 1 \le \frac{t}{a} + a^t \iff a^t - 1 \ge t\left(1 - \frac{1}{a}\right) \iff 1 - \frac{1}{a} \le \frac{a^t - 1}{t}.$$

Объединяя обе оценки, получаем, что для всех $t \in (0, 1]$ функция $f(t)$ не убывает и ограничена:
$$1 - \frac{1}{a} \le f(t) \le a - 1.$$

**Шаг 3 (Существование предела справа при $t \to 0_+$).**
Положим
$$L := \inf \{ f(t) \mid t \in (0, 1] \}.$$
В силу ограниченности снизу величиной $1 - \frac{1}{a}$ точная нижняя грань $L$ конечна. Покажем, что $L = \lim\limits_{t \to 0_+} f(t)$.
По определению точной нижней грани ($\inf$):
$$\forall \varepsilon > 0 \ \exists t_\varepsilon \in (0, 1]: \quad L \le f(t_\varepsilon) < L + \varepsilon.$$
Так как функция $f(t)$ не убывает, для всех $t \in (0, t_\varepsilon)$ выполняется цепочка неравенств:
$$L \le f(t) \le f(t_\varepsilon) < L + \varepsilon \implies |f(t) - L| < \varepsilon.$$
По определению предела функции это означает, что существует правосторонний предел:
$$\lim_{t \to 0_+} f(t) = L, \quad \text{причём } 1 - \frac{1}{a} \le L \le a - 1.$$

**Шаг 4 (Существование предела слева и совпадение односторонних пределов).**
Найдём предел при стремлении аргумента к нулю слева. Пусть $-t < 0$, где $t \to 0_+$. Тогда:
$$\frac{a^{-t} - 1}{-t} = \frac{\frac{1}{a^t} - 1}{-t} = -\frac{1 - a^t}{a^t \cdot t} = \frac{1}{a^t} \cdot \frac{a^t - 1}{t}.$$
Переходя к пределу при $t \to 0_+$ и учитывая непрерывность показательной функции ($\lim\limits_{t \to 0_+} a^t = a^0 = 1$), получаем:
$$\lim_{t \to 0_+} \frac{a^{-t} - 1}{-t} = \lim_{t \to 0_+} \frac{1}{a^t} \cdot \lim_{t \to 0_+} \frac{a^t - 1}{t} = 1 \cdot L = L.$$
Таким образом, пределы слева и справа в точке $0$ совпадают и равны $L =: \ell(a)$ (то есть функцию $f(t)$ можно доопределить в точке $t = 0$ значением $L$ по непрерывности). $\blacksquare$
