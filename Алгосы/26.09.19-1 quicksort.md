
# **Конспект: Быстрая сортировка (QuickSort)**

## **1. Основные принципы и концепция**

* **Стратегия:** Алгоритм основан на подходе **«разделяй и властвуй»**.
* **Базовый случай:** Одноэлементный массив всегда является отсортированным, что выступает условием выхода из рекурсии.
* **Рекурсивный процесс:** На спуске рекурсии происходит разбиение массива (Partition) и рекурсивные запуски для сформированных подмассивов, а на возврате из рекурсии — сборка отсортированного массива.
* **Принцип работы:** Ключевым этапом алгоритма является процедура разбиения (Partition), изменяющая порядок элементов в подмассиве `a[l...r]` без использования дополнительной памяти.

---

## **2. Реализация на C++ (Схема разбиения Ломуто)**

В лекционном материале подробно разбирается схема разбиения Ломуто. В качестве опорного элемента (**pivot**) выбирается самый правый элемент подмассива `a[r]`.

### **Код алгоритма:**

```cpp
#include <algorithm>

// Функция разбиения подмассива a[l...r] по схеме Ломуто
int partition(int a[], int l, int r) {
    int pivot = a[r];    // pivot — опорный элемент
    int i = l - 1;       // i — граница элементов, меньших или равных опорному

    for (int j = l; j < r; j++) { // Перебор элементов подмассива
        if (a[j] <= pivot) {     // Элемент меньше или равен опорному
            i = i + 1;           // Увеличиваем границу
            std::swap(a[i], a[j]); // Помещаем элемент в блок меньших
        }
    }
    std::swap(a[i + 1], a[r]);   // Ставим pivot на его итоговую позицию i + 1
    return i + 1;                // Возвращаем индекс опорного элемента
}

// Главная рекурсивная функция быстрой сортировки
void quicksort(int a[], int l, int r) {
    if (l < r) {                 // Условие выхода из рекурсии
        int q = partition(a, l, r); // Разбиение массива

        quicksort(a, l, q - 1);  // Рекурсивный запуск для левой части
        quicksort(a, q + 1, r);  // Рекурсивный запуск для правой части
    }
}
```

### **Пояснение работы Partition:**
1. Поддерживается переменная `i`, обозначающая текущую границу элементов, меньших либо равных `pivot`.
2. Проход по подмассиву индексом `j` проверяет условие `a[j] <= pivot`.
3. По завершении цикла опорный элемент меняется местами с `a[i + 1]`, благодаря чему он оказывается строго между элементами, которые меньше его (слева), и элементами, которые больше его (справа).

## **3. Оценка сложности и свойства**

### **Сложность по памяти (Space Complexity)**
* **Память в процедуре Partition:** Составляет **\\(O(1)\\)**, так как используются только локальные переменные и указатели (`i`, `j`).
* **Память на стек рекурсии:**
  * **В среднем случае:** Глубина рекурсивного дерева равна **\\(O(\log n)\\)**, поэтому для точек возврата в стеке требуется **\\(O(\log n)\\)** памяти.
  * **В худшем случае:** Если массив делится крайне несбалансированно (на подмассивы размера \\(n, n-1, n-2 \dots\\)), глубина рекурсии возрастает до **\\(O(n)\\)**, требуя **\\(O(n)\\)** памяти в стеке.
* Лекция делает отсылку к учебнику Кормена для детального математического доказательства.

### **Устойчивость (Stability)**
* Быстрая сортировка является **неустойчивой (unstable)**: в процессе перестановки элементов исходный относительный порядок одинаковых ключей не сохраняется.

## **4. Пополнение конспекта (Теоретические дополнения и оптимизации)**

### **Временная сложность (Time Complexity)**
* **Лучший случай — \\(O(n \log n)\\):** Возникает, когда каждый выбор `pivot` делит подмассив на две равные части.
* **Средний случай — \\(O(n \log n)\\):** Математическое ожидание времени работы на случайных данных составляет \\(O(n \log n)\\).
* **Худший случай — \\(O(n^2)\\):** Происходит при статическом выборе крайнего элемента в качестве `pivot` на уже отсортированном или обратном массиве.

### **Способы предотвращения худшего случая**
1. **Рандомизированный выбор (Randomized QuickSort):** Выбор случайного индекса \\(k \in [l, r]\\) и выполнение `swap(a[k], a[r])` перед вызовом `partition`. Гарантирует \\(O(n \log n)\\) в среднем независимо от порядка входных данных.
2. **Медиана трёх (Median-of-Three):** В качестве `pivot` выбирается медиана из первого, среднего и последнего элементов подмассива: \\(\text{median}(a[l], a[(l+r)/2], a[r])\\).

### **Практические оптимизации**
* **Устранение хвостовой рекурсии:** Выполнение рекурсивного вызова только для меньшего из двух подмассивов, а для большего — переход к итерации цикла. Это гарантирует ограничение глубины стека величиной \\(O(\log n)\\).
* **Порог для сортировки вставками:** Для подмассивов небольшого размера (\\(n \le 16\\)) эффективнее использовать **Insertion Sort**.
* **Интроспективная сортировка (IntroSort):** Начинает с QuickSort, но если глубина рекурсии превышает \\(2 \log n\\), алгоритм автоматически переключается на **HeapSort**, предотвращая худший случай \\(O(n^2)\\).
