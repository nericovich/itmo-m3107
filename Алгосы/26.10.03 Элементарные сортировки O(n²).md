# Конспект: Элементарные сортировки O(n²)

Конспект охватывает три классических элементарных алгоритма сортировки: **пузырьковую сортировку (Bubble Sort)**, **сортировку вставками (Insertion Sort)** и **сортировку выбором (Selection Sort)**.

---

## 1. Сортировка вставками (Insertion Sort)

### 1.1. Принцип работы
* **Разделение массива:** Массив разделяется на отсортированную часть (изначально состоит из одного элемента `A[0]`) и неотсортированную часть (`A[1...n-1]`).
* **Пошаговый процесс:** Начиная со второго элемента (`j = 1`), алгоритм берет текущий элемент (`key = A[j]`), ищет для него подходящую позицию в отсортированной части слева и вставляет его туда.
* **Оптимизация сдвигом вместо swap:** Вместо применения серии последовательных вызовов `swap(A[i], A[i+1])` (требующих 3 присваивания на каждый обмен), элементы отсортированной части, которые больше `key`, сдвигаются вправо на одну позицию (`A[i+1] = A[i]`). Затем `key` записывается в освободившееся место. Это сокращает число операций присваивания примерно в 3 раза.

### 1.2. Реализация на C++

```cpp
#include <iostream>
#include <vector>

void insertionSort(std::vector<int>& A) {
    int n = A.size();
    for (int j = 1; j < n; j++) {
        int key = A[j];        // Сохраняем вставляемый элемент
        int i = j - 1;         // Граница отсортированной части
        
        // Сдвигаем элементы, которые больше key, вправо
        while (i >= 0 && A[i] > key) {
            A[i + 1] = A[i];
            i = i - 1;
        }
        A[i + 1] = key;        // Вставляем key на нужную позицию
    }
}
```

### 1.3. Инвариант цикла
* **Формулировка:** В начале каждой итерации внешнего цикла `for` по индексу `j` подмассив `A[0...j-1]` состоит из элементов, изначально находившихся в `A[0...j-1]`, но расположенных в отсортированном порядке.
* **Инициализация:** При `j = 1` подмассив `A[0...0]` состоит из одного элемента и заведомо отсортирован.
* **Сохранение:** В теле цикла элементы `A[j-1], A[j-2]...`, большие `key`, сдвигаются вправо, сохраняя отсортированный порядок после вставки `key`.
* **Завершение:** По окончании цикла `j = n`, подмассив `A[0...n-1]` содержит все элементы исходного массива в отсортированном порядке.

### 1.4. Сложность и свойства
* **Временная сложность:**
  * **Худший случай:** $O(n^2)$ (массив отсортирован в обратном порядке; выполняется $\sum_{j=1}^{n-1} j = \frac{n(n-1)}{2}$ сравнений и сдвигов).
  * **Средний случай:** $O(n^2)$ (с меньшим коэффициентом постоянной благодаря эффективным сдвигам).
  * **Лучший случай:** $O(n)$ (исходный массив уже отсортирован; условие `while` ложно на первой же проверке).
* **Сложность по памяти:** $O(1)$ (требует постоянного объема дополнительной памяти для переменных `key`, `i`, `j`).
* **Устойчивость (Stability):** **Устойчивая** (элементы с равными ключами не меняют свой относительный порядок, так как условие сдвига строгое: `A[i] > key`).

## 2. Сортировка выбором (Selection Sort)

### 2.1. Принцип работы
* **Идея:** В неотсортированном подмассиве от `i` до `n-1` находится минимальный элемент.
* **Обмен:** Найденный минимум меняется местами с первым неотсортированным элементом `A[i]`.
* **Продвижение границы:** Индекс `i` увеличивается, и процесс повторяется для оставшейся неотсортированной части.
* **Связь с HeapSort:** Сортировка выбором тратит $O(n)$ времени на поиск минимума на каждом шаге ($n$ раз), что даёт $O(n^2)$. Замена линейного поиска минимума/максимума на извлечение из двоичной кучи (Max-Heap / Min-Heap) приводит к алгоритму пирамидальной сортировки (**HeapSort**) со сложностью $O(n \log n)$.

### 2.2. Реализация на C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

void selectionSort(std::vector<int>& A) {
    int n = A.size();
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i; // Предполагаем, что текущий элемент минимальный
        
        // Ищем индекс минимального элемента в оставшейся части
        for (int j = i + 1; j < n; j++) {
            if (A[j] < A[minIndex]) {
                minIndex = j;
            }
        }
        
        // Меняем местами найденный минимум с A[i]
        if (minIndex != i) {
            std::swap(A[i], A[minIndex]);
        }
    }
}
```

### 2.3. Сложность и свойства
* **Временная сложность:**
  * **Худший, средний и лучший случаи:** **$O(n^2)$**. Число сравнений всегда фиксировано и равно $\frac{n(n-1)}{2}$, независимо от начальной упорядоченности данных.
* **Число обменов:** Выполняется ровно $O(n)$ операцией `swap` (не более $n-1$ обменов), что делает сортировку выбором полезной при высокой стоимости записи в память.
* **Сложность по памяти:** $O(1)$ дополнительной памяти.
* **Устойчивость (Stability):** **Неустойчивая** в стандартной реализации (далекий обмен `swap` может переместить элемент через одинаковые с ним значения).

## 3. Пузырьковая сортировка (Bubble Sort)

### 3.1. Принцип работы
* **Идея:** Алгоритм делает последовательные проходы по массиву, сравнивая соседние элементы `A[j]` и `A[j+1]`.
* **«Всплытие» элементов:** Если `A[j] > A[j+1]`, они меняются местами. За один полный проход наибольший элемент неотсортированной части «всплывает» на свою итоговую позицию в конце массива.
* **Оптимизация флагом `swapped`:** Если за весь проход по массиву не произошло ни одного обмена, массив уже отсортирован, и выполнение алгоритма можно досрочно завершить.

### 3.2. Реализация на C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

void bubbleSort(std::vector<int>& A) {
    int n = A.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false; // Флаг наличия обменов
        
        for (int j = 0; j < n - i - 1; j++) {
            if (A[j] > A[j + 1]) {
                std::swap(A[j], A[j + 1]);
                swapped = true;
            }
        }
        
        // Если обменов не было, массив отсортирован
        if (!swapped) {
            break;
        }
    }
}
```

### 3.3. Сложность и свойства
* **Временная сложность:**
  * **Худший случай:** $O(n^2)$ (массив отсортирован в обратном порядке).
  * **Средний случай:** $O(n^2)$.
  * **Лучший случай:** $O(n)$ (при использовании флага `swapped` для отсортированного массива выполняется $n-1$ сравнений и 0 обменов).
* **Сложность по памяти:** $O(1)$ дополнительной памяти.
* **Устойчивость (Stability):** **Устойчивая** (соседние элементы с равными ключами не меняются местами).

## 4. Сравнительный анализ алгоритмов $O(n^2)$

| Алгоритм | Время (Лучший) | Время (Средний) | Время (Худший) | Доп. память | Устойчивость | Число обменов |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Сортировка вставками** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | Да | $O(n^2)$ (сдвигов) |
| **Сортировка выбором** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | Нет | $O(n)$ |
| **Пузырьковая сортировка** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | Да | $O(n^2)$ |

---

### Главные выводы:
1. **Сортировка вставками** — наиболее эффективная из простых сортировок на практике, особенно на частично отсортированных данных или небольших массивах (используется как базовая часть в гибридных алгоритмах, таких как Timsort и IntroSort).
2. **Сортировка выбором** минимизирует количество записей в память ($O(n)$ обменов), но делает фиксированное число сравнений $O(n^2)$ в любых случаях.
3. **Пузырьковая сортировка** уступает по производительности вставкам из-за большого числа парных обменов, однако с флагом `swapped` способна определять отсортированность за $O(n)$.
