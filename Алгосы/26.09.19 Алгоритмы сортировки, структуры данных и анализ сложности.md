### 1.2. Фильтрация и сортировка по нескольким полям
Частая задача: отобрать первокурсников определенных групп и упорядочить их **по группе**, а внутри каждой группы — **по алфавиту**.

:::: tabs

=== Python
```python
students = [
    Student("Иванов И.", 1, "M3101", 18, 123456),
    Student("Петров П.", 1, "M3102", 19, 123457),
    Student("Алексеев А.", 1, "M3101", 18, 123458),
]

# 1. Фильтрация (1 курс, группы M3101 и M3102)
filtered = [
    s for s in students 
    if s.course == 1 and s.group in {"M3101", "M3102"}
]

# 2. Многокритериальная сортировка:
# Первичный ключ — группа, вторичный — имя по алфавиту
filtered.sort(key=lambda s: (s.group, s.name))
```

=== C++
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <set>

int main() {
    std::vector<Student> students = {
        {"Иванов И.", 1, "M3101", 18, 123456},
        {"Петров П.", 1, "M3102", 19, 123457},
        {"Алексеев А.", 1, "M3101", 18, 123458}
    };

    // 1. Фильтрация
    std::set<std::string> target_groups = {"M3101", "M3102"};
    std::vector<Student> filtered;
    for (const auto& s : students) {
        if (s.course == 1 && target_groups.count(s.group)) {
            filtered.push_back(s);
        }
    }

    // 2. Многокритериальная сортировка через лямбда-компаратор
    std::sort(filtered.begin(), filtered.end(), [](const Student& a, const Student& b) {
        if (a.group != b.group) {
            return a.group < b.group; // Сначала по группе
        }
        return a.name < b.name;       // Затем по алфавиту
    });
}
```

## 2. Сортировка вставками (Insertion Sort)

### 2.1. Идея и принцип работы
Массив делится на две части:
1. **Отсортированная часть** — изначально состоит из одного элемента `A[0]` (один элемент всегда упорядочен относительно себя).
2. **Неотсортированная часть** — элементы от `A[1]` до `A[n-1]`.

На каждом шаге $j$ элемент `key = A[j]` вставляется на подходящее место в уже отсортированную левую часть.

---

### 2.2. Оптимизация: Сдвиги (Shift) вместо обменов (Swap)
* **Наивный вариант (`swap`)**: Поэлементно меняем текущий элемент с предыдущим, пока он меньше. Каждый `swap` требует 3 присваивания. При сдвиге на $k$ позиций влево выполняется $3k$ операций.
* **Оптимальный вариант (со сдвигом)**:
  1. Сохраняем вставляемый элемент: `key = A[j]`.
  2. Сдвигаем элементы, которые строго больше `key`, вправо: `A[i + 1] = A[i]`.
  3. В освободившуюся позицию один раз записываем `key`: `A[i + 1] = key`.
  * *Выигрыш:* вместо $3k$ операций записи выполняется всего $k + 2$ (сокращение операций записи в 3 раза).

---

### 2.3. Реализация алгоритма

:::: tabs

=== Python
```python
def insertion_sort(arr: list[int]) -> None:
    n = len(arr)
    for j in range(1, n):
        key = arr[j]
        i = j - 1
        # Ищем место для key, сдвигая большие элементы вправо
        while i >= 0 and arr[i] > key:
            arr[i + 1] = arr[i]
            i -= 1
        arr[i + 1] = key

# Пример вызова:
# data = [7, 4, 1, 3, 2, 5, 2, 8, 11]
# insertion_sort(data)
# print(data) -> [1, 2, 2, 3, 4, 5, 7, 8, 11]
```

=== C++
```cpp
#include <vector>

void insertionSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int j = 1; j < n; ++j) {
        int key = arr[j];
        int i = j - 1;
        // Ищем место для key, сдвигая большие элементы вправо
        while (i >= 0 && arr[i] > key) {
            arr[i + 1] = arr[i];
            --i;
        }
        arr[i + 1] = key;
    }
}
```

### 2.4. Анализ сложности Insertion Sort
* **По времени:**
  * **Лучший случай (Best):** $O(n)$ — массив уже отсортирован, условие `arr[i] > key` ложно сразу, внутренний `while` не делает итераций.
  * **Средний случай (Average):** $O(n^2)$ — каждый элемент смещается в среднем на половину отсортированной части.
  * **Худший случай (Worst):** $O(n^2)$ — массив отсортирован в обратном порядке:
    $$T(n) = \sum_{j=1}^{n-1} j = \frac{n(n-1)}{2} \sim O(n^2)$$
* **По памяти:** $O(1)$ — сортировка на месте (*in-place*), используются 3 локальные переменные (`key`, `i`, `j`).

## 3. Инвариант цикла (Loop Invariant)

**Инвариант цикла** — логическое утверждение о состоянии данных, истинное перед началом каждой итерации цикла и после её завершения.

### Структура доказательства корректности (3 шага):
1. **Инициализация (Initialization):** Утверждение истинно перед первой итерацией.
2. **Сохранение (Maintenance):** Если утверждение истинно перед шагом $k$, оно остается истинным перед шагом $k+1$.
3. **Завершение (Termination):** При выходе из цикла утверждение гарантирует, что алгоритм решил поставленную задачу.

### Доказательство для Insertion Sort:
* **Инвариант:** Перед началом каждой итерации внешнего цикла по $j$ подмассив $A[0 \dots j-1]$ состоит из тех же исходных элементов, но уже расположенных по возрастанию.
* **1. Инициализация:** При $j = 1$ подмассив $A[0 \dots 0]$ состоит из 1 элемента $\implies$ всегда отсортирован.
* **2. Сохранение:** Внутренний цикл сдвигает все элементы $A[i] > key$ вправо и ставит `key` на позицию, где $A[i] \le key$. Подмассив $A[0 \dots j]$ становится отсортированным.
* **3. Завершение:** Цикл завершается при $j = n$. Подмассив $A[0 \dots n-1]$ отсортирован $\implies$ весь массив упорядочен.

## 4. Парадигма «Разделяй и властвуй» (Divide and Conquer)

Метод декомпозиции состоит из трех последовательных шагов:
1. **Разделение (Divide):** Дробление задачи на несколько меньших подзадач того же типа.
2. **Властвование (Conquer):** Рекурсивное решение подзадач. Если размер задачи минимален (базовый случай) — решаем напрямую.
3. **Комбинирование (Combine):** Сборка общего решения из решений подзадач.

### Пример: Рекурсивный подсчет суммы массива

:::: tabs

=== Python
```python
def recursive_sum(arr: list[int], left: int, right: int) -> int:
    # Базовый случай: подмассив из 1 элемента
    if left == right:
        return arr[left]
    
    # 1. Divide (делим пополам)
    mid = (left + right) // 2
    
    # 2. Conquer (рекурсивно считаем половины)
    left_sum = recursive_sum(arr, left, mid)
    right_sum = recursive_sum(arr, mid + 1, right)
    
    # 3. Combine (складываем результаты)
    return left_sum + right_sum

# Пример:
# arr = [4, 5, 1, 9, 13, 11, 7]
# res = recursive_sum(arr, 0, len(arr) - 1) # 50
```

=== C++
```cpp
#include <vector>

int recursiveSum(const std::vector<int>& arr, int left, int right) {
    // Базовый случай: 1 элемент
    if (left == right) {
        return arr[left];
    }
    
    // 1. Divide
    int mid = left + (right - left) / 2;
    
    // 2. Conquer
    int left_sum = recursiveSum(arr, left, mid);
    int right_sum = recursiveSum(arr, mid + 1, right);
    
    // 3. Combine
    return left_sum + right_sum;
}
```

## 5. Сортировка слиянием (Merge Sort)

### 5.1. Принцип работы
* **Divide:** Делим полуинтервал $[left, right)$ пополам: $mid = \lfloor(left + right) / 2\rfloor$.
* **Conquer:** Рекурсивно сортируем $[left, mid)$ и $[mid, right)$. Базовый случай: $left + 1 \ge right$ (0 или 1 элемент).
* **Combine (`merge`):** Сливаем две отсортированные части с помощью двух указателей и вспомогательного массива. Если одна часть закончилась, остаток другой дописывается («доливается хвост»).

---

### 5.2. Реализация алгоритма

:::: tabs

=== Python
```python
def merge(arr: list[int], left: int, mid: int, right: int) -> None:
    it1 = 0  # указатель для левой части [left, mid)
    it2 = 0  # указатель для правой части [mid, right)
    result = []

    # Основной шаг слияния
    while left + it1 < mid and mid + it2 < right:
        # Условие <= обеспечивает устойчивость алгоритма
        if arr[left + it1] <= arr[mid + it2]:
            result.append(arr[left + it1])
            it1 += 1
        else:
            result.append(arr[mid + it2])
            it2 += 1

    # Доливаем оставшийся левый хвост
    while left + it1 < mid:
        result.append(arr[left + it1])
        it1 += 1

    # Доливаем оставшийся правый хвост
    while mid + it2 < right:
        result.append(arr[mid + it2])
        it2 += 1

    # Копируем отсортированный результат обратно в исходный массив
    for i, val in enumerate(result):
        arr[left + i] = val


def merge_sort(arr: list[int], left: int, right: int) -> None:
    # Базовый случай: отрезок из 0 или 1 элемента
    if left + 1 >= right:
        return
    
    mid = (left + right) // 2
    merge_sort(arr, left, mid)
    merge_sort(arr, mid, right)
    merge(arr, left, mid, right)
```

=== C++
```cpp
#include <vector>

void merge(std::vector<int>& arr, int left, int mid, int right) {
    int it1 = 0; // указатель для левой части [left, mid)
    int it2 = 0; // указатель для правой части [mid, right)
    int len = right - left;
    std::vector<int> result(len);

    // Основной шаг слияния
    while (left + it1 < mid && mid + it2 < right) {
        // Условие <= обеспечивает устойчивость
        if (arr[left + it1] <= arr[mid + it2]) {
            result[it1 + it2] = arr[left + it1];
            it1++;
        } else {
            result[it1 + it2] = arr[mid + it2];
            it2++;
        }
    }

    // Доливаем левый хвост
    while (left + it1 < mid) {
        result[it1 + it2] = arr[left + it1];
        it1++;
    }

    // Доливаем правый хвост
    while (mid + it2 < right) {
        result[it1 + it2] = arr[mid + it2];
        it2++;
    }

    // Копируем обратно в исходный массив
    for (int i = 0; i < len; ++i) {
        arr[left + i] = result[i];
    }
}

void mergeSort(std::vector<int>& arr, int left, int right) {
    // Базовый случай: отрезок длины <= 1
    if (left + 1 >= right) {
        return;
    }
    
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid, right);
    merge(arr, left, mid, right);
}
```

### 5.3. Математический вывод сложности Merge Sort

#### Временная сложность:
Рекуррентное уравнение:
$$T(n) = \begin{cases} O(1), & n = 1 \\ 2T(n/2) + O(n), & n > 1 \end{cases}$$

Развертка по уровням:
$$\begin{aligned}
T(n) &= 2T(n/2) + O(n) \\
&= 4T(n/4) + 2O(n/2) + O(n) = 4T(n/4) + 2O(n) \\
&= 2^k T\left(\frac{n}{2^k}\right) + k \cdot O(n)
\end{aligned}$$

При $2^k = n \implies k = \log_2 n$:
$$T(n) = n \cdot T(1) + \log_2 n \cdot O(n) = O(n \log n)$$
Сложность **$O(n \log n)$** одинакова в лучшем, среднем и худшем случаях.

#### Сложность по памяти:
* Вспомогательный массив для слияния: $O(n)$.
* Стек рекурсивных вызовов (глубина дерева): $O(\log n)$.
* Итого: $M(n) = O(n) + O(\log n) = O(n)$.

## 6. Свойства асимптотических оценок ($O, \Omega, \Theta$)

Пусть $T_1(n) = O(g_1(n))$, $T_2(n) = O(g_2(n))$, а $C$ — константа.

1. **Сумма:** $T_1(n) + T_2(n) = O(\max(g_1(n), g_2(n)))$
2. **Произведение:** $T_1(n) \cdot T_2(n) = O(g_1(n) \cdot g_2(n))$
3. **Умножение на константу:** $C \cdot T_1(n) = O(g_1(n))$
4. **Сложение с константой:** $T_1(n) + C = O(g_1(n))$
5. **Теорема о связи:** 
   $$T(n) = \Theta(g(n)) \iff \begin{cases} T(n) = O(g(n)) & \text{(ограничение сверху)} \\ T(n) = \Omega(g(n)) & \text{(ограничение снизу)} \end{cases}$$

## 7. Устойчивость сортировок (Stability)

### 7.1. Определение
**Устойчивая (стабильная) сортировка** — алгоритм, сохраняющий исходный относительный порядок элементов с одинаковыми значениями ключа.

* Исходный массив: $[3_a, 1, 3_b]$
* **Устойчивая:** $[1, 3_a, 3_b]$ (порядок $3_a$ и $3_b$ сохранен)
* **Неустойчивая:** $[1, 3_b, 3_a]$ (порядок нарушен)

---

### 7.2. Демонстрация сохранения порядка при многостадийной сортировке

Если отсортировать список сначала по вторичному ключу, а затем **устойчивой сортировкой** по первичному — данные окажутся корректно упорядочены по обоим критериям.

:::: tabs

=== Python
```python
@dataclass
class Item:
    group: str
    score: int

items = [
    Item("M3101", 59),
    Item("M3102", 58),
    Item("M3101", 85),
    Item("M3102", 70)
]

# Шаг 1: Сортируем по баллу (по убыванию)
items.sort(key=lambda x: x.score, reverse=True)

# Шаг 2: Стабильно сортируем по группе
# Python-метод list.sort() гарантированно устойчив (Timsort)
items.sort(key=lambda x: x.group)

# Результат: внутри каждой группы баллы останутся отсортированы по убыванию!
# for it in items: print(it)
# -> Item('M3101', 85), Item('M3101', 59), Item('M3102', 70), Item('M3102', 58)
```

=== C++
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

struct Item {
    std::string group;
    int score;
};

int main() {
    std::vector<Item> items = {
        {"M3101", 59},
        {"M3102", 58},
        {"M3101", 85},
        {"M3102", 70}
    };

    // Шаг 1: Сортируем по баллу (по убыванию)
    std::stable_sort(items.begin(), items.end(), [](const Item& a, const Item& b) {
        return a.score > b.score;
    });

    // Шаг 2: Устойчиво сортируем по группе
    std::stable_sort(items.begin(), items.end(), [](const Item& a, const Item& b) {
        return a.group < b.group;
    });

    // Внутри групп порядок по баллам сохранился
    // for (const auto& it : items) {
    //     std::cout << it.group << " " << it.score << "\n";
    // }
}
```

### 7.3. Условия устойчивости для рассмотренных алгоритмов
* **Insertion Sort:**
  * **Устойчив**, если условие сдвига строгое: `arr[i] > key`. Равный элемент не двигается левее своих дубликатов.
  * Если написать `arr[i] >= key`, алгоритм станет **неустойчивым**.
* **Merge Sort:**
  * **Устойчив**, если при равенстве элементов берется элемент из левой половины: `arr[left + it1] <= arr[mid + it2]`.
  * Если написать `<`, алгоритм станет **неустойчивым**.
